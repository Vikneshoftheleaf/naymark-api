NAYMARK API

Remove a supported Gemini watermark,
one request at a time.

Upload an image you created or are authorized to modify. The API runs Naymark's visible-watermark detector and returns a PNG for you to review.

API VERSION 0.1JSON ERRORS · PNG OUTPUT
01

Quickstart

Send a Gemini-generated image containing the known visible watermark template supported by Naymark. Use multipart form data and name the file field file.

CURL
curl -X POST https://naymark.vercel.app/v1/process \
  -F "file=@image.png;type=image/png" \
  --output processed.png

↳ The response body is the PNG itself. Save it as a file or pass the bytes to your image pipeline.

03

Code examples

Use the same endpoint from your preferred language.

Python

PYTHON · REQUESTS
import requests

with open("image.png", "rb") as image:
    response = requests.post(
        "https://naymark.vercel.app/v1/process",
        files={"file": ("image.png", image, "image/png")},
        timeout=60,
    )
    response.raise_for_status()

with open("processed.png", "wb") as output:
    output.write(response.content)

JavaScript

JAVASCRIPT · FETCH
const form = new FormData();
form.append("file", imageFile);

const response = await fetch(
  "https://naymark.vercel.app/v1/process",
  { method: "POST", body: form }
);

if (!response.ok) throw new Error("Image processing failed");
const processedImage = await response.blob();
04

Responses & errors

Successful requests return the processed PNG bytes with Content-Type: image/png. Matching and pixel reconstruction are approximate; check the result against your original. Errors return JSON from FastAPI.

400Empty or invalid image.
413Upload or image dimensions exceed the limit.
415Unsupported image format.
422Image processing failed or output is too large.
ERROR RESPONSE
{
  "detail": "The uploaded image is invalid."
}
05

Limits & privacy

  • Maximum upload4 MiB
  • Maximum image size12 megapixels
  • Maximum dimension8,000 px
  • Response cachingDisabled

This API is public and does not require an API key. Anyone with the URL can use it. Only upload images you created or are authorized to modify. The service does not intentionally store uploaded or processed image content.

06

Use Naymark in Python

The API is powered by the Naymark Python package. Install it to run supported visible-watermark matching directly in your own Python application. It processes images locally and does not upload them to this API.

INSTALL
pip install naymark
PYTHON
import cv2
from naymark import remove_watermark

image = cv2.imread("image.png")
result = remove_watermark(image)
processed = getattr(result, "image", result)
cv2.imwrite("processed.png", processed)

Naymark is designed for its supported visible watermark template in Gemini-generated images, not arbitrary watermarks. Reconstruction is approximate; inspect the output. It does not target invisible provenance signals. Naymark is an independent project and is not affiliated with Google or Gemini.
