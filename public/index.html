HOW IT WORKS

From upload to output.

Send an authorized Gemini-generated image with Naymark's supported visible watermark. Get a processed PNG back.

01

Upload your image

Choose an image you created or are authorized to modify.

02

Match the watermark

Naymark looks for its supported visible Gemini watermark template.

03

Review the result

Compare the output with your original. Pixel reconstruction is approximate.

BUILT FOR DEVELOPERS

One request.
A clean response.

Use the API from any language that can send a multipart request. No SDK required.

See all examples ↗
QUICK START · CURL 
curl -X POST https://naymark.vercel.app/v1/process \
  -F "file=@image.png;type=image/png" \
  --output processed.png
Returns image/png · Cache-Control: no-store
THE PYTHON PACKAGE

Meet the engine
behind the API.

Naymark is the Python package behind this API. Run it locally in Python, or call this API from your app. It targets its known visible watermark template, not arbitrary watermarks or invisible provenance signals.
