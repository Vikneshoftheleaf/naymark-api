QUICK START · CURL 
curl -X POST https://naymark.vercel.app/v1/process \
  -F "file=@image.png;type=image/png" \
  --output processed.png
Returns image/png · Cache-Control: no-store
THE PYTHON PACKAGE

Meet the engine
behind the API.

Naymark is the Python package behind this API. Run it locally in Python, or call this API from your app. It targets its known visible watermark template, not arbitrary watermarks or invisible provenance signals.
